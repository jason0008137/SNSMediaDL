# SNSMediaDL

フォローしている作者の作品を X / Misskey / Mastodon / pixiv から取得し、
閲覧・フィルター・タグ付けができるローカルのライブラリにまとめます。

- **すべて自分のパソコンの中で動きます** —— アップロードなし、登録なし、API キー不要
- **再実行しても取り直しません** —— 新しいものだけを追加します
- **Web インターフェース付き** —— サムネイル一覧、レーティングとコンテンツ種別の
  タグ、5 段階評価、お気に入り、同じ作者のプラットフォームをまたぐアカウントを
  まとめて見る機能

| プラットフォーム | 取得方法 | ログイン |
|------------------|----------|----------|
| X（Twitter）| Chrome 拡張機能 | 必要 —— ブラウザの既存のログインをそのまま使います |
| Misskey | インターフェースに URL を貼る | 不要（公開コンテンツ）|
| Mastodon（baraag.net など）| インターフェースに URL を貼る | 不要（公開コンテンツ）|
| pixiv | インターフェースに URL を貼る | 必要 —— `PHPSESSID` を自分で設定します |

現時点で実際に使用しているのは Windows 10 / 11 のみです。

---

## ⚠ 使う前に

インストールの前に、この 4 点を読んでください。

- **これは個人用のアーカイブツールであって、サービスではありません。**
  `127.0.0.1` のみで待ち受け（つまりこのパソコンからしか接続できません）、
  **認証は意図的に実装していません** —— そのポートに到達できるものは、
  ダウンロード履歴をすべて読めますし、ダウンロードを指示することもできます。
  外部に公開したりポートフォワードしたりしないでください。それは全部を
  公開するのと同じです。
- **取得の責任は利用者にあります。** 各プラットフォームの利用規約、著作権、
  取得したものの扱いは、すべて利用者の責任です。本プロジェクトは有料の壁や
  アクセス制限を回避する手段を提供しません —— 読み取るのは「ログイン済みの
  ブラウザで元々見えている内容」だけです。
- **速度の上限を上げないでください。** X を速く取得しすぎるとアカウントが
  ロックされます。ロックされるのはあなたのアカウントです。下の
  「ゆっくり取得する」を参照してください。
- **認証情報を流出させないでください。** pixiv の `PHPSESSID` は `config.toml`
  に書きます。このファイルはどこにもアップロードされませんが、中身を他人に
  貼らないでください。

## 二、インストール

### 1. コードを取得する

「コマンドプロンプト」または PowerShell を開き、置きたい場所（例：`D:\`）に
移動して実行します。

```
git clone https://github.com/jason0008137/SNSMediaDL.git
cd SNSMediaDL
```

> GitHub のページで **Code → Download ZIP** を使っても構いませんが、その場合は
> 一括更新が使えません（あとから接続できます。「更新」の節を参照）。

### 2. 起動する

フォルダー内の **`start.bat` をダブルクリック**します。

初回は必要なパッケージを自動でインストールするため数分かかります。2 回目以降は
数秒です。次の行が出れば起動しています。

```
  API 文件   http://127.0.0.1:8765/docs
```

**その黒い画面は開いたままにしてください** —— それがプログラム本体です。
閉じるとプログラムが止まります。止めたいときは `Ctrl + C` を押します。

### 3. インターフェースを開く

ブラウザで **<http://127.0.0.1:8765/>** を開きます。これがメイン画面です。

### 4. Chrome 拡張機能を入れる（X を取得する場合のみ）

1. Chrome のアドレスバーに `chrome://extensions` と入力します
2. 右上の「**デベロッパーモード**」をオンにします
3. 「**パッケージ化されていない拡張機能を読み込む**」を押し、このプロジェクトの
   **`extension`** フォルダーを選びます
4. アドレスバー右のパズルのアイコンから SNSMediaDL をピン留めします

アイコンをクリックして、緑の点（backend 接続済み）が出れば完了です。
（赤い点の場合は、たいてい `start.bat` が起動していません。）

> ⚠ 拡張機能自体の説明（`extension/README.md`）は現在**正體中文のみ**です。
> これは既知の不足であり、三言語化の対象外です。

### フォルダー内の 3 つの `.bat`

| ファイル | 用途 |
|----------|------|
| `start.bat` | プログラムを起動します（普段はこれだけ使います）|
| `update.bat` | 最新版に更新します |
| `status.bat` | ダウンロード待ちがどれくらい残っているかを素早く確認します |

## 三、使い方

### X から取得する

1. `start.bat` が起動していることを確認します
2. Chrome で `https://x.com/<アカウント名>/media` を開きます
3. **画面の右下に小さい丸いボタンが出ます** —— クリックするとパネルが開きます
   （パネルはドラッグでき、位置は記憶されます）
4. **下にスクロールします** —— パネルの数字が自動的に増えていきます。
   必要な深さまでスクロールしてください
5. 必要なら、パネルでレーティングとコンテンツ種別を選びます。このまとまりの
   投稿はそのタグ付きで保存されます
6. 「**送信してダウンロード N 件**」を押します。パネルが 0 になるまで進捗を
   表示します

先に知っておくとよいこと。

- **今見ているアカウントのものだけを収集します。** サイドバーのおすすめや、
  ホームのタイムラインでたまたま流れたものは混ざりません。
- **一度に 1 アカウントです。** 次の人を取得するには、移動して、スクロールして、
  もう一度押します。
- **`start.bat` が起動していなくても収集はできます。** データは一旦ブラウザに
  残り、プログラムを起動してから送信すれば追いつきます。
- 既に見たページはブラウザのキャッシュから読まれるため、スクロールしても
  新しいデータが出ないことがあります —— ページを再読み込みしてからもう一度
  スクロールしてください。

### Misskey / Mastodon / pixiv から取得する

Web インターフェース →「**取得**」タブ → URL を貼る（**1 行に 1 件**）→
解析プレビューを確認 → 問題なければ送信します。

次の形式を受け付けます。

```
https://misskey.io/@someone
https://baraag.net/@artist
https://www.pixiv.net/users/12345
@artist@baraag.net
```

- **X の URL は弾かれます** —— そちらは拡張機能で取得します
- 認識できない URL はその旨をはっきり伝えます。推測はしません

**新作を追加する**：同じページで「**一括更新**」を押します。追跡中の全アカウントを
1 回ずつ差分取得し、取得済みのものは取りません。

### 閲覧と整理

**「メディア」タブ** —— サムネイル一覧。プラットフォーム、アカウント、
レーティング、コンテンツ種別、評価、お気に入りで絞り込めます。サムネイルを
クリックすると拡大表示と詳細が出ます。選択モードにすると、まとめてタグ付け
できます（Shift による範囲選択、ページ全選択に対応）。

**「アカウント」タブ** —— 各アカウントの既定レーティングを設定し、同じ作者の
複数のアカウント（プラットフォームをまたぐもの、サブアカウントを含む）を
1 人の「作者」にまとめられます。まとめると、その人の全作品を一度に見られます。

**右上の ⚙** —— よく使う 3 つのスイッチ。

| 項目 | 既定 | 説明 |
|------|------|------|
| バックグラウンドダウンロード | **オフ** | オンにすると、保留中のものを自動的に処理します |
| セーフモード | **オン** | メディアページで R18 のものを表示せず、ヘッダーにその旨を出します |
| 問題とログ | — | ダウンロード失敗の一覧、失敗理由、再試行 |

## 四、ファイルの保存先

既定ではプロジェクト内の `downloads\`。構造は
`downloads\プラットフォーム\アカウント\ファイル名` です。

**別のドライブに変えるには**：`config.toml.example` をコピーし、`config.toml`
という名前にして（同じ階層に置きます）、次の行を変更します。

```toml
output_root = 'D:\SNS_Media'
```

> Windows のパスは**シングルクォート**で囲んでください。ダブルクォートだと
> `\` がエスケープ文字として扱われ、読み込みに失敗します。

変更後、`start.bat` を再起動すると反映されます。

⚠️ **パスを変えても既存のファイルは移動しません。** 古いファイルはその場に残り、
記録も有効なままですが、インターフェースで見え続けるようにするには古いフォルダーを
`extra_media_roots` に列挙する必要があります（書き方は example ファイルにあります）。

`config.toml` では他にもファイル名の書式、ダウンロードの速度、pixiv の
`PHPSESSID` などを設定できます。各項目の横に説明があります。不要なものは
コメントのままで構いません。

## 五、更新

**`update.bat` をダブルクリックします。** 最新版を取得し、必要なときだけ
パッケージを入れ、データベースの構造が変わったときだけ構造を更新します。

**あなたのデータには触れません** —— ダウンロードしたファイル、データベース、
`config.toml` はいずれも更新の対象外です。構造が本当に変わるときは、先に
データベースのバックアップを作ってから実行します。

- 「**Chrome 拡張機能も更新されました**」と出た場合：プログラム起動後に通常は
  自動で再読み込みされます。されない場合は `chrome://extensions` で再読み込み
  ボタンを押してください
- 最初に **ZIP をダウンロード**した場合：初回に更新元をその場で接続するか
  尋ねられます。`y` と答えてください（データはそのままですが、自分で変更した
  コードは上書きされます）
- 「**保存していない変更があります**」と出た場合：コードを変更しています。
  残さなくてよければ、表示されたコマンドを実行してください

## 六、ゆっくり取得する

**X を速く取得しすぎると、アカウント全体が 1 日ほどロックされます。**
既定値は意図的に控えめです（同時 4 件、1 秒間隔）。確信がなければ上げないで
ください。

実際にレート制限に掛かった場合、プログラムは**その回をすぐに止め**、取得できて
いないものを「保留中」に戻し、「問題とログ」に 1 行記録します。
**自動では再試行しません** —— いつ再開してよいかを知っているのはあなただけです。

## 七、困ったとき

| 症状 | 対処 |
|------|------|
| `start.bat` が一瞬で閉じる | Python が未インストール、またはインストール時に「Add Python to PATH」を入れていません。入れ直してください |
| Web ページが開かない | `start.bat` の黒い画面は開いたままですか |
| 拡張機能が赤い点（backend オフライン）を出す | 上と同じ。またはアイコンをクリックしてアドレスが `http://127.0.0.1:8765` か確認してください |
| いくらスクロールしても数字が動かない | アカウントの `/media` ページか確認してください（ホームは収集しません）。キャッシュの場合は再読み込みしてからスクロールしてください |
| パネルが赤字でアカウントを特定できないと出る | そのタブを再読み込みしてください |
| 送信は成功したのにファイルがない | 通常はパネルが理由を出します。⚙ →「問題とログ」でも確認できます |
| 途中で止まる | たいていはレート制限です。ログに記録されます。しばらく待ってから再試行を押してください |

⚙ →「**問題とログ**」が最初に見る場所です。失敗の理由はすべてそこに記録されます。

---

## 八、まだできないこと

- **スケジュール実行やポーリングはありません** —— 取得は自分で押します
- **pixiv は `PHPSESSID` を自分で設定する必要があり**（場所は
  `config.toml.example` にあります）、実サイトでの大量検証はまだです
- X の動画は mp4 があるものだけ取得します。ストリーミング専用の形式は
  スキップして記録します
- 変換、映像と音声の結合、EXIF の書き込みは行いません
- アカウントの記録を削除してから取り直すと、ディスクに残っているファイルの
  `xxx (1).jpg` のような複製ができます
- ライブラリが非常に大きいとサムネイル一覧が重くなります
